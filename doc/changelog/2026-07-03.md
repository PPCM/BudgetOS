# Changelog - 2026-07-03

## Summary
Audit-driven fixes across two batches. Batch 1 (priorities + HTTP bug): fixed the
HTTP "blank page" on Docker, hardened the session secret, fixed a credit-card IDOR,
moved payee uploads to the persisted volume, fixed forecast arithmetic on
MariaDB/PostgreSQL and split persistence. Batch 2 (remaining issues): additional
backend correctness/security fixes, cross-DB fixes, frontend UX/correctness fixes,
and dependency vulnerability remediation. Batch 3 (test suite): fixed the 78
pre-existing client test failures and centralized the i18n mock (client 431/431).

## Changes

- [src/config/index.js] Reworked session secret handling: reject known-weak/short secrets in production, auto-generate and persist a strong secret to `data/.session-secret` when none is provided; added centralized `httpsEnabled` → `session.secure` flag driving both the Secure cookie and the CSP HTTPS upgrade.
- [src/middleware/security.js] Gated CSP `upgrade-insecure-requests` on `config.session.secure` instead of `!isDev` — fixes the blank page on plain-HTTP installs (browser no longer upgrades asset requests to HTTPS).
- [src/middleware/session.js] Use centralized `config.session.secure` for the cookie Secure flag.
- [src/models/CreditCard.js] `generateCycleDebit`: filter the card by `user_id` (IDOR fix) and recompute the debited account balance within the transaction.
- [src/models/Transaction.js] Persist `is_split` on insert so split transactions load their splits.
- [src/services/forecastService.js] Coerce decimal amounts with `Number()` (planned amounts, deferred debits, account balances, monthly aggregates) — fixes NaN forecasts on pg/mysql (string decimals).
- [src/controllers/uploadController.js] Store payee images under the persisted uploads volume (`config.paths.uploads/payees`) instead of `client/public/uploads`; updated delete path resolution; removed orphaned `__dirname`/`fileURLToPath`.
- [src/app.js] Serve `/uploads` via `express.static` in all environments; exclude `/uploads` from the SPA fallback so missing images return 404.
- [client/vite.config.js] Added `/uploads` dev proxy to the backend.
- [docker/Dockerfile] Create `uploads/payees` instead of `client/public/uploads/payees`.
- [docker/docker-compose.yml] Removed the hardcoded weak `SESSION_SECRET`; documented auto-generation and the HTTP/HTTPS `COOKIE_SECURE` behavior.
- [.gitignore] Ignore `client/public/uploads/`.
- [.dockerignore] Ignore `client/public/uploads`.

## Changes (batch 2 — remaining issues)

Backend correctness:
- [src/models/Transaction.js] Fixed transfer sign bugs: editing the destination leg no longer flips both legs; a type change without an amount now recomputes the sign. Added `validateReferences()` (category/payee/credit-card ownership) called from create/update. `reconcile()` returns the real affected-row count.
- [src/services/importService.js] Renamed the `config` param to `parseConfig` (module-shadowing bug: temp import files were never deleted). Import reconciliation now sets `status='reconciled'` alongside the flag.
- [src/models/PlannedTransaction.js] `advanceNextOccurrence` now enforces `max_occurrences` and re-anchors the day-of-month to the start date (a "31st" schedule no longer drifts to the 28th). `createOccurrence` has an idempotency guard against duplicate occurrences after a crash/restart.
- [src/services/schedulerService.js] Scheduler query skips planned transactions that reached `max_occurrences`.
- [src/services/forecastService.js] Occurrences dated "today" are no longer excluded (calendar-date comparison).
- [src/services/reportService.js] `getMonthComparison` coerces SUM() strings to Number (avoids divide-by-"0.00" → NaN/Infinity).
- [src/models/Account.js] `reactivate()` recomputes the balance (updateBalance is a no-op while inactive).
- [src/utils/bankPatterns.js] `extractPurchaseDate` rejects out-of-range day/month.
- [src/database/dateHelpers.js] Added `likeOperator()` (ILIKE on PostgreSQL); used in Transaction/forecast search so search is case-insensitive on all engines.
- [src/database/migrations/023_import_longtext.js] Widen imports.parsed_data/match_results to LONGTEXT on MySQL/MariaDB (no-op on SQLite/PostgreSQL).

Security:
- [src/middleware/csrf.js] Constant-time CSRF token comparison (crypto.timingSafeEqual).
- [src/routes/auth.js] Rate-limit the validate-reset-token route.
- [src/models/Rule.js] Guard the user-supplied regex operator (try/catch + pattern-length cap) against invalid patterns / ReDoS.

Frontend (client/):
- [Import.jsx] Fixed the Tab CSV delimiter (`value={'\t'}`).
- [Accounts/Categories/PlannedTransactions/Rules.jsx] Converted `invalidateQueries(['key'])` to the v5 object signature (was invalidating the whole cache).
- [tailwind.config.js] Added a safelist for dynamic color classes (selected-state borders were invisible).
- [Rules.jsx] Delete confirmation modal + onError handlers on mutations.
- [Dashboard/Reports/Import.jsx] Added error states.
- [utils.js/useFormatters.js] `parseLocalDate()` fixes date display off-by-one; default form dates use `formatLocalDate`.
- [PlannedTransactions/Rules/Settings.jsx] Use the shared axios instance (CSRF/401/403 handling) instead of raw axios.
- [api.js] Only retry on genuine CSRF_TOKEN_INVALID (not on real authorization denials).
- [Toast.jsx] useMemo instead of useCallback for the context value. [AdminUsers.jsx] key-based re-init of the edit modal. [Settings.jsx] added CAD currency.

Config / dependencies:
- [package.json, client/package.json] `npm audit fix` in both (prod deps: multer, nodemailer, tmp/exceljs, qs, axios, form-data, react-router-dom). Client now reports 0 vulnerabilities. Tightened the `qs` override to `>=6.15.2`; bumped `engines.node` to `>=20` (root + client).
- [docker/docker-compose.yml] Image tag `budgetos:1.0.0` → `budgetos:latest`.
