# Changelog - 2026-02-16

## Summary
Added number format preferences (decimal separator, digit grouping) configurable at system, group, and user levels. Created FormattedAmountInput component for all monetary inputs with auto-formatting, grouping symbols, and smart decimal handling. Updated terminology to "Symbole de groupement des chiffres". Translated all 9 locales.
