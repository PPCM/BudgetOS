# Changelog - 2026-02-17

## Summary
Created reusable PasswordInput component with show/hide toggle (eye icon) and applied it to all 8 password fields across 5 pages. Fixed FormattedAmountInput bugs: dot grouping interpreted as decimal, "." key ignored when grouping=dot, digitGrouping "none" rejected by validator. Replaced Settings error banners with toasts. Adjusted AdminGroups modal layout. Added same-separator validation (frontend + backend) with i18n support in all 9 locales.
