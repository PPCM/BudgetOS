# Changelog - 2026-03-29

## Summary
Major UI improvements based on user feedback: account tabs for grouping transactions and recurring entries, clickable account cards, budget projection per account, and user interface preferences (persistent modals, projection expanded by default).

## Changes

- [src/database/migrations/021_add_ui_preferences.js] Created migration adding modal_persistent and projection_expanded columns to user_settings
- [src/models/User.js] Added modal_persistent and projection_expanded to allowedFields and formatSettings
- [src/services/reportService.js] Added getProjections() method for budget projection per account (end of month + 30 days) and advanceDate() helper for frequency calculations
- [src/controllers/reportController.js] Added getProjections endpoint
- [src/routes/reports.js] Added GET /projections route
- [client/src/components/Modal.jsx] Added modalPersistent setting support to disable close-on-click-outside
- [client/src/pages/Settings.jsx] Added Interface section in Preferences with toggles for modalPersistent and projectionExpanded
- [client/src/pages/Transactions.jsx] Added account tabs bar with deep-link support (?account=id), hide COMPTE column when account selected, pre-fill account in new transaction modal
- [client/src/pages/PlannedTransactions.jsx] Added account tabs filtering both "À venir" and list panels, pre-fill account in modal, show account name in "Tous" tab, fixed {{date}} interpolation in "Prochaine" label
- [client/src/pages/Dashboard.jsx] Made account cards clickable (→ /transactions?account=id), added "Voir tout" link, added 5th StatCard for end-of-month projection, added estimated balance per account
- [client/src/pages/Accounts.jsx] Added "Voir les transactions" link per card, added collapsible projection section per account (end of month + 30 days), respects projectionExpanded user setting
- [client/src/lib/api.js] Added getProjections() to reportsApi
- [client/src/locales/fr.json] Added i18n keys for interface settings, projection, dashboard.viewAll, accounts.viewTransactions
- [client/src/locales/en.json] Added i18n keys for interface settings, projection, dashboard.viewAll, accounts.viewTransactions
- [client/src/locales/{de,es,it,pt,ru,sv,zh}.json] Added i18n keys for interface settings, projection, dashboard, accounts
- [tests/unit/services/reportService.projection.test.js] Created 10 unit tests for advanceDate() frequency calculations
- [tests/unit/models/userSettings.test.js] Created 4 unit tests for formatSettings with new UI preference fields

## Notes
- Budget projection is based on active planned transactions (recurring) and their next_occurrence dates
- Account tabs use URL search params for deep-linking (?account=id)
- The account dropdown filter is hidden when an account tab is selected to avoid redundancy
