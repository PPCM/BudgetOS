# Changelog - 2026-01-30

## Summary
Added frontend admin pages for user management, group management, and system settings (super_admin only).

## Changes

- [client/src/lib/api.js] Added adminApi and groupsApi namespaces with endpoints for admin user management, group CRUD, member management, and system settings; added `adminApi.updateUser()` endpoint
- [client/src/components/Layout.jsx] Added conditional admin navigation section in sidebar for super_admin users (Users, Groups, System links with Shield, FolderTree, Cog icons)
- [client/src/App.jsx] Added AdminRoute component for super_admin-only access, added 3 admin routes (/admin/users, /admin/groups, /admin/settings)
- [client/src/pages/AdminUsers.jsx] Created admin user management page with search/filter, create/edit user modal (UserModal), role dropdown, suspend/reactivate actions, role badges, edit button per user, group management section in edit mode (add/remove/change role in groups), locale and currency fields in edit mode
- [client/src/pages/AdminGroups.jsx] Created admin group management page with group cards, create/edit modals, expandable member panels, add/remove/update member functionality
- [client/src/pages/AdminSettings.jsx] Created admin system settings page with public registration toggle and default group selector
- [client/tests/pages/AdminUsers.test.jsx] Created unit tests (39 tests): rendering, filters, create modal, edit modal (pre-fill, groups display, add/remove group, update group role, update user), suspend/reactivate, role dropdown
- [client/tests/pages/AdminGroups.test.jsx] Created unit tests (26 tests): rendering, group CRUD, member panel, add/remove members
- [client/tests/pages/AdminSettings.test.jsx] Created unit tests (17 tests): rendering, toggle, default group select, save functionality

- [src/database/connection.js] Added seeds directory config to knex configuration (fixes db:seed path resolution)
- [budgetos.sh] Created server management script with start, stop, restart, status, logs, reset, and build commands
- [doc/budgetos-cli.md] Created documentation for server management script (commands, env vars, examples)
- [tests/scripts/budgetos-sh.test.sh] Created unit tests (29 tests): help, unknown command, status, start, stop, restart, logs, stale PID handling
- [src/models/User.js] Added `status` field to format(), added `findByIdAny()` for admin operations on inactive users, added `search` and `status` filters to `findAll()`, fixed `reactivate()` and `updateRole()` to use `findByIdAny()`, added `adminUpdate()` for partial user update by admin (email uniqueness check, allowed fields: email, first_name, last_name, role, locale, currency)
- [src/validators/admin.js] Added `updateUserSchema` Zod schema for partial user update (all fields optional: email, firstName, lastName, role, locale, currency)
- [src/controllers/adminController.js] Added `search` and `status` query params to `listUsers`, fixed `suspendUser` to return updated user data, added `updateUser` handler with self-role-modification protection, fixed `getUser` to use `findByIdAny` instead of `findById`
- [src/routes/admin.js] Added PUT `/admin/users/:userId` route with `requireSuperAdmin` middleware and `updateUserSchema` validation

## Notes
All admin pages are protected by AdminRoute which checks for super_admin role. Non-admin users are redirected to the dashboard.
