# Changelog - 2026-01-23

## Summary

Reorganized test file structure to match CLAUDE.md conventions, added missing unit tests, and implemented toast notification system.

## Changes

- [client/src/pages/Transactions.jsx] Fixed handleSave to send toAccountId: null when selecting external transfer; added TransactionTypeIcon component showing transaction type (TrendingUp for income, TrendingDown for expense, ArrowLeftRight for transfer with rotation for incoming/outgoing); added external source option for transfers (allows incoming transfers from external sources); added validation for at least one account in transfers; simplified handleSave to send raw data with positive amount; fixed handleEdit to correctly display external source transfers (swap accountId/toAccountId for incoming transfers); replaced all alert() calls with toast notifications (useToast hook); added success toasts for create/update/delete operations
- [client/src/components/Toast.jsx] Created toast notification system with ToastProvider context and useToast hook; supports success, error, warning, info types with configurable duration
- [client/src/main.jsx] Added ToastProvider wrapper to enable toast notifications app-wide
- [src/validators/transactions.js] Made accountId nullable in createTransactionSchema and updateTransactionSchema for external source transfers; added refine validation to ensure at least one account is set
- [src/models/Transaction.js] Added support for external source transfers (no source account, only destination) - creates single transaction with positive amount on destination; added update logic to convert internal transfer to external source transfer (moves transaction to destination account with positive amount, deletes linked transaction)
- [vitest.config.js] Updated include path to tests/**/*.test.js
