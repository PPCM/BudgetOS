# Changelog - 2026-01-28

## Summary
Completed full migration from sql.js to Knex.js for multi-database support (SQLite, MySQL/MariaDB, PostgreSQL). All models, services, controllers, and tests have been migrated. All 179 tests pass.

## Changes

- [src/models/CreditCard.js] Rewrote entire model to use Knex.js query builder instead of raw SQL via sql.js; all methods are now async; replaced SQLite-specific expiration date filtering (SUBSTR/strftime/CAST) with JS-side filtering using parseExpirationValue/isExpired helpers
- [src/models/PlannedTransaction.js] Rewrote to use Knex.js query builder: replaced query.get/all/run with Knex methods, all static methods now async, uses dateHelpers for date operations
- [src/models/Transaction.js] Rewrote entire model to use Knex.js query builder; all static methods now async; replaced dbTransaction with knex.transaction; passes trx to Account.updateBalance to prevent SQLite deadlocks
- [src/models/Account.js] Added optional trx parameter to updateBalance method for proper transaction propagation with better-sqlite3
- [src/controllers/importController.js] Replaced query.all/query.get with Knex query builder (knex('imports').where().first()), removed dependency on old connection.js query export
- [src/controllers/creditCardController.js] Already had await on all method calls (no changes needed)
- [src/controllers/plannedTransactionController.js] Already had await on all method calls (no changes needed)
- [src/controllers/payeeController.js] Already had await on all Payee model calls
- [src/controllers/ruleController.js] Already had await on all Rule model calls
- [src/controllers/categoryController.js] Already had await on all Category model calls
- [src/controllers/authController.js] Already had await on User model calls
- [src/controllers/accountController.js] Already had await on all Account model calls
- [src/controllers/reportController.js] Already had await on all service calls
- [src/controllers/transactionController.js] Already had await on all Transaction model calls
- [src/database/migrate.js] Rewrote to use Knex migrations (knex.migrate.latest) instead of raw SQL schema.sql
- [src/database/seed.js] Rewrote to use Knex seeds (knex.seed.run) instead of raw SQL inserts
- [tests/models/Account.test.js] Rewrote to use in-memory Knex (better-sqlite3) instance with vi.mock pattern; single beforeAll/afterAll at file level
- [tests/models/PlannedTransaction.test.js] Rewrote to use in-memory Knex instance with vi.mock pattern; single beforeAll/afterAll at file level; mocks Transaction.create
- [tests/models/CreditCard.test.js] Created unit tests for format, formatCycle, parseExpirationValue, isExpired helpers
- [tests/models/Transaction.test.js] Rewrote to use in-memory Knex instance; fixed transfer update/delete deadlocks by passing trx to Account.updateBalance
- [package.json] Removed sql.js dependency; added test:sqlite, test:mysql, test:postgres, test:all-dbs, db:migrate:rollback scripts
