# Changelog - 2026-01-21

## Summary

Added manual bank reconciliation feature with sortable columns, quick date filters, reconciliation status filter, and configurable first day of week preference.

## Changes

- [src/models/Transaction.js] Added toggleReconcile() method to toggle reconciliation status, added isReconciled filter and sortBy options (payee, category, account) to findByUser()
- [src/controllers/transactionController.js] Added toggleReconcile controller handler
- [src/routes/transactions.js] Added PATCH /:id/reconcile route for toggling reconciliation
- [src/validators/transactions.js] Added isReconciled filter and sortBy options (payee, category, account) to listTransactionsQuerySchema
- [client/src/lib/api.js] Added toggleReconcile() API method in transactionsApi
- [client/src/pages/Transactions.jsx] Added reconciliation mode with toggle button, green highlighting for reconciled transactions, checkmark icons for toggling status, table-fixed layout, filter for reconciled/non-reconciled transactions, sortable column headers with visual indicators, reduced page size to 10 for infinite scroll, quick date period filters dropdown (week, 7 days, month, 30 days, year, 365 days), and fixed date formatting for local timezone
- [client/src/pages/Settings.jsx] Added weekStartDay preference in PreferencesSettings
- [client/src/contexts/AuthContext.jsx] Added userSettings state and updateSettings function, load settings on login/register
- [client/src/lib/api.js] Added getSettings and updateSettings methods to authApi
- [doc/bank-reconciliation.md] Created documentation for the bank reconciliation feature, added sections for filtering, sorting, and quick date periods
- [README.md] Added manual reconciliation and transactions features to features list, added PATCH reconcile endpoint to API documentation

## Notes

The reconciliation mode hides edit/delete buttons to prevent accidental modifications during the reconciliation process.
