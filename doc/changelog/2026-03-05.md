# Changelog - 2026-03-05

## Summary
Implemented password reset feature with SMTP email infrastructure. Users can now recover their password via email link from the login page. Admins can configure SMTP settings via the admin UI.

## Changes

- [package.json] Added nodemailer dependency
- [src/config/index.js] Added smtp configuration section (SMTP_HOST, SMTP_PORT, SMTP_SECURE, SMTP_USER, SMTP_PASS, SMTP_FROM, APP_URL)
- [src/database/migrations/020_create_password_reset_tokens.js] Created password_reset_tokens table migration
- [src/models/PasswordResetToken.js] Created PasswordResetToken model with create, findByTokenHash, markUsed, deleteExpired, generateToken, hashToken
- [src/services/emailService.js] Created EmailService with SMTP config from DB/env, sendMail, sendPasswordResetEmail (bilingual HTML template), testConnection
- [src/validators/auth.js] Added forgotPasswordSchema, resetPasswordSchema, validateResetTokenSchema
