# Changelog - 2026-02-02

## Summary
Fix all 8 Dependabot security alerts (4 high, 4 medium) by replacing vulnerable dependencies, adding npm overrides, and upgrading ESLint to v9. Add Simplified Chinese (zh), Russian (ru), German (de), Spanish (es), Italian (it), and Portuguese (pt) translations. Replace inline language selector buttons with an elegant dropdown menu featuring emoji flags and native language names. Add FormLanguageSelect reusable component for form-based language selection, integrated in admin user creation/edit modal. Add Docker support: multi-stage Dockerfile for production image, docker-compose.yml with SQLite/MariaDB/PostgreSQL examples, rename existing docker/ to docker-db/ for test databases.
