# Changelog - 2026-01-22

## Summary

Added performance optimizations, unit tests, fixed payee creation, and fixed HTML entity encoding issue.

## Changes

- [src/models/Transaction.js] Fixed NULLS LAST for SQLite using CASE expression for nullable sort fields (payee, category, account); enhanced update() to sync linked transfer transactions (shared fields like description/date/amount are updated on both, destination account changes delete old linked tx and create new one)
- [client/src/lib/iconMap.js] Created selective icon import map (~150 icons) to reduce bundle size
- [client/src/lib/utils.js] Added formatLocalDate() and getDatePeriod() utility functions
- [client/src/pages/Transactions.jsx] Extracted SortIcon and CategoryIcon components, added useDeferredValue for search debounce, memoized handlers with useCallback, implemented optimistic updates for toggle reconcile, simplified transfer account display (show only current account instead of both), fixed handleSave to send toAccountId: null when selecting external transfer (was not sending the field, preventing linked transaction deletion)
- [client/src/components/SearchableSelect.jsx] Fixed new item creation: input value now preserved after creating new payee/category (value not reset before query refresh)
- [src/middleware/validation.js] Fixed sanitizeInput: removed encoding of apostrophes, quotes, and ampersands (corrupted legitimate text like "C'est" → "C&#x27;est"). Now only escapes < and > for HTML tag prevention
- [src/database/fix-html-entities.js] Created migration script to fix existing corrupted data with HTML entities
- [client/vitest.config.js] Created Vitest configuration for client tests
- [client/src/test/setup.js] Created test setup file with jest-dom
- [client/src/lib/utils.test.js] Created 25 unit tests for utility functions (cn, formatCurrency, formatDate, formatDateRelative, formatLocalDate, getDatePeriod)
- [client/src/lib/iconMap.test.js] Created 13 unit tests for icon mapping (getIconComponent, aliases)
- [client/src/components/SearchableSelect.test.jsx] Created 18 unit tests for SearchableSelect component (rendering, filtering, selection, creation, keyboard navigation)
- [vitest.config.js] Created Vitest configuration for backend tests
- [src/tests/setup.js] Created test database setup with in-memory SQLite
- [src/tests/transaction.test.js] Created 17 unit tests for Transaction model (filtering, sorting, NULLS LAST behavior, pagination, toggleReconcile)
- [src/tests/validation.test.js] Created 15 unit tests for sanitizeInput function (preserves apostrophes, quotes, ampersands; escapes HTML tags)
- [src/validators/transactions.js] Added toAccountId field to updateTransactionSchema for transfer modifications
- [src/tests/setup.js] Added createTestTransfer helper function for testing linked transactions
- [src/tests/transaction.test.js] Added 5 unit tests for transfer update functionality (sync fields, amount signs, destination account changes)

## Notes

- Tests cover the new sorting functionality including NULLS LAST behavior for nullable fields
